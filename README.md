# casthex

Cast CSV/TSV hex tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/casthex/

## Install / run

```bash
git clone https://github.com/theworker02/casthex.git
cd casthex
node src/cli.js
node --test
```
